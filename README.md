# Habits Tracker API

Бэкенд-часть SPA веб-приложения для трекера полезных привычек. 
В основе проекта лежит книга Джеймса Клира «Атомные привычки».

## Технологии
- Python (Django, Django REST Framework)
- PostgreSQL / SQLite (база данных)
- Celery + Redis (асинхронные задачи и брокер сообщений)
- Telegram Bot API (отправка напоминаний)
- drf-spectacular (Swagger документация)
- JWT (авторизация)

## Функционал
- Регистрация и авторизация пользователей (JWT).
- CRUD операций с привычками (каждый пользователь видит только свои).
- Просмотр публичных привычек.
- Валидаторы: нельзя указать вознаграждение и связанную привычку одновременно, время на выполнение не более 120 сек, и т.д.
- Пагинация (по 5 привычек на страницу).
- Асинхронная отправка напоминаний в Telegram через Celery.

## Запуск проекта локально

1. Клонируйте репозиторий:
   **git clone <ссылка_на_репозиторий>**
   **cd habits-tracker**

2. Создайте и активируйте виртуальное окружение:
   **python -m venv .venv**
   Для Windows:
   **.venv\Scripts\activate**
   Для Linux/macOS:
   **source .venv/bin/activate**

3. Установите зависимости:
   **pip install -r requirements.txt**

4. Создайте файл `.env` на основе `.env.template` и заполните его своими данными (ключи, токен бота):
   **cp .env.template .env**

5. Выполните миграции:
   **python manage.py migrate**

6. Запустите сервер разработки:
   **python manage.py runserver**

7. Для работы Celery откройте еще два терминала (не забудьте активировать `.venv`):
   Терминал для Worker:
   **celery -A config worker -l info -P solo**
   Терминал для Beat:
   **celery -A config beat -l info**
